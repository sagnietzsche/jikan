## jikan

an open source terminal based time tracker .

### run

```sh
go run .
```

### keys

- `j` / `k`: move through projects
- `space` / `enter`: start or stop the selected project timer
- `n`: add a new project
- `r`: reset the selected project
- `q`: quit

This first version keeps time in memory only. Persistence and richer project
features can be added on top of the current Bubble Tea model.
